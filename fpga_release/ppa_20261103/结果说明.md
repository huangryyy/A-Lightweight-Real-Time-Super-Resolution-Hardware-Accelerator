这是 **Vivado 布线后无向量活动传播估算**，没有导入 SAIF/VCD 图像工作负载。工具还提示高扇出复位网络活动假设可能影响准确性。因此可在技术文档中写“布线后片上功耗粗估约 10.33 W”，不可写成实测板卡功耗或据此直接推导实测 FPS/W。

主要报告条件：typical 工艺、环境温度 25°C、板温 25°C、250 LFM 风速、medium 散热器、medium 板尺寸及 12–15 层板设置。这些是报告采用的模型条件，并非本次测得的实际散热环境。该值不包含外置 DDR 芯片、板卡电源转换损耗、风扇及 Linux 主机功耗；PCIe 高速收发器功耗按当前 IP 配置估算，不等同于历史主机协商链路下的实测值。

后续若要提高功耗估算可信度，应在正确的非复位工作状态下导入代表性图像任务活动数据，并与板卡供电端实测进行交叉验证。

## 复现命令

原中文路径下运行的独立 IP 综合曾触发 Vivado 内部 `TclStackFree` 错误；本次改用指向同一目录的纯英文盘符后完成构建。请在能够使用 Vivado 的 PowerShell 中映射一个空闲盘符，并从新的输出目录开始：

```powershell
subst P: 'D:\Vivado\FPGA_嵌赛'
& 'D:/Vivado/Vivado/2023.2/bin/vivado.bat' -mode batch -nojournal -log 'P:/ppa_rebuild.log' -source 'P:/vivado_scripts/run_ppa.tcl' -tclargs 'P:/build/ppa_rebuild'
```

P: 已被其他用途占用时应换用空闲盘符，并相应修改命令。脚本为每个启用独立综合检查点的顶层 IP 创建任务；随顶层综合的复位 IP 不单独创建综合任务。综合/实现任务并行数为 4，顶层工具线程上限为 6。输出位于参数指定的构建目录。

本次实际构建目录为 `build/ppa_ascii_20261103_101705`，其中保留完整工程及 Top_routed.dcp。该工程引用 P: 路径，重新打开时需要上述盘符映射。本目录只汇集文本报告，便于提交和引用。

使用完后可执行 `subst P: /D` 移除临时映射；不影响实际文件。
